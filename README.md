# Vortix releases

Release artifacts for the Vortix panel: full install/update tarballs
(`p2ptv-vX.Y.Z-linux-amd64.tar.gz`) published as **GitHub Releases** (not in git).
Each is built with `make package` from the panel source, clean of any licence
issuer or signing material.

- Download: Releases tab, or `gh release download <tag> -R obscuremind/vortix-releases`.
- Verify: each release lists its tarball `sha256`.
- Private repo. Licence records live in the separate `vortix-licenses` repo.
